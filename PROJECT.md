# epub2pdf-by-jair-lima

## Descrição
Conversor de EPUB para PDF A5 de qualidade de impressão, usando o Word para a paginação.

## Stack
Python 3, python-docx, BeautifulSoup, lxml, Pillow, pywin32; requer Microsoft Word no Windows.

## Estrutura
Ver a lista de arquivos na raiz e o README.md.

## Comando essencial
`python epub2pdf.py livro.epub livro.pdf`

## Estado atual
Versão pública inicial (2026-10-17), extraída do projeto original do autor.

## Problemas conhecidos
Testado apenas no Windows.
